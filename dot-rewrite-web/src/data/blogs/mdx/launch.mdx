# Welcome to .note

If you're reading this, thanks for checking out .note!

## Setting Up Your Account

Getting started with .note is simple:

1. **Sign up for an account** - Head to the homepage and click "Get Started"
2. **Choose your plan** - Select Free (.note is free)
3. **Test it out** - Write your first note and prompt Dot
